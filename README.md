# Español — личный тренажёр

Автономный тренажёр испанского языка без Base44 и внешних сервисов.

## Что умеет

- показывает только вопрос, без встроенных ответов и подсказок;
- принимает несколько правильных вариантов;
- открывает ответ только по кнопке «Посмотреть ответ»;
- сохраняет прогресс и ошибки в браузере;
- позволяет повторять ошибочные задания;
- позволяет добавлять собственные задания прямо на сайте.

Все упражнения находятся в массиве `BUILTIN` внутри `index.html`. Для обновления сайта достаточно изменить этот файл — GitHub Pages опубликует изменения автоматически.

> Прогресс и собственные задания хранятся только в localStorage текущего браузера.
